My Shift 2026 APK Project

මෙය APK එක සෑදීමට සූදානම් Android project එකකි. මෙය දැනටමත් APK file එකක් නොවේ.
GitHub Actions මඟින් APK එක build කරගත හැක.

Phone එකෙන්:
1. ZIP එක extract කරන්න.
2. GitHub හි අලුත් repository එකක් සාදා මේ ZIP එකේ ඇතුළත files upload කරන්න (ZIP එක පමණක් upload කිරීම ප්‍රමාණවත් නැත; extract කර files upload කරන්න).
3. Repository එකේ Actions tab එකට යන්න.
4. "Build My Shift APK" workflow එක තෝරන්න.
5. Run workflow ඔබන්න.
6. Build අවසන් වූ පසු run එකේ Artifacts යටතේ "My-Shift-2026-APK" download කරන්න.
7. ZIP artifact එක extract කර app-debug.apk file එක Android phone එකට download/install කරන්න.
8. Android security prompt එකේ අවසර දෙන්න. Install වූ පසු app icon එක app drawer එකේ පෙනේ; Home Screen එකට අවශ්‍ය නම් icon එක long-press කර Add to Home screen කරන්න.

සටහන:
- APK එක debug-signed build එකකි, සාමාන්‍යයෙන් පෞද්ගලික භාවිතයට සුදුසුයි.
- Android install අවසරය user විසින්ම දෙන්න ඕන.
- Shift pattern සහ team offsets app එකේ තිබෙන වත්මන් දත්ත අනුවය; මුල් shift card එක සමඟ නැවත පරීක්ෂා කරන්න.
